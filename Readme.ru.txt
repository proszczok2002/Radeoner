Radeoner 1.06 — руководство пользователя

Radeoner — лёгкая переносимая панель AMD для Windows 10/11 x64 с Microsoft
.NET Framework 4.8. Достаточно драйвера AMD с ADLX; панель Adrenalin не нужна.
Запустите Radeoner.exe из папки с правом записи. Дополнительные службы для
регулировки GPU не устанавливаются.

ЯЗЫК И ОФОРМЛЕНИЕ
Настройки > Язык: Polski, English, Deutsch, Русский, Español, Français.
Темы: системная, светлая и тёмная. Размер текста: 100–200 процентов.
Изменения действуют сразу. Полная справка доступна без интернета по F1.
Исходные переводы — UTF-8-файлы lang/*.lng в GitHub. Новые языки встроены
в EXE, отдельная установка языковых пакетов не нужна.

ВОЗМОЖНОСТИ ВИДЕОКАРТЫ
Выберите GPU в верхнем списке. Показания, Отчёт и Настройки остаются доступны.
Регулировка и Вентилятор показаны, только если соответствующие функции
доступны; у дискретных карт есть также вход в дополнительную подсветку RGB.
Неподдерживаемые напряжения, частоты и кривые не выводятся как поля ввода.
Если встроенная GPU поддерживает отдельные функции, они остаются доступны.
В ноутбуке охлаждением может управлять прошивка. Значок встроенной GPU не
упоминает GPU-вентилятор. У других GPU обороты появляются только при наличии
достоверного показания. Значение 0 RPM допустимо и означает остановку.

КЛАВИАТУРА И NVDA
Tab / Shift+Tab: переход по полям. Ctrl+Tab / Ctrl+Shift+Tab: следующая и
предыдущая доступная вкладка. Ctrl+1–5: Показания, Регулировка, Вентилятор,
Отчёт, Настройки. Недоступные функции пропускаются. F5: перечитать настройки.
F6: выделить и прочитать состояние операции. F1: справка. Числа можно вводить
либо изменять стрелками вверх/вниз. Каждое поле содержит имя, единицу,
значение и допустимый диапазон. В списке показаний стрелки выбирают строки,
Ctrl+A выделяет все, Ctrl+C копирует. Alt+F4 скрывает программу в трей.
Выход завершает её полностью. Windows+B переводит к области уведомлений;
выберите Radeoner и нажмите Enter для открытия. В меню значка есть Выход.

ИЗМЕНЕНИЕ ПАРАМЕТРОВ
Проверьте значения, измените их и выберите Применить или Ctrl+Enter. Только
подтверждение записывает параметры GPU. Запуск и чтение ничего не меняют.
Диапазоны и шаг задаёт драйвер. Navi4 и более новые GPU могут предоставлять
смещение частоты/напряжения, а не абсолютное значение: читайте описание поля.
Процентный лимит мощности не равен TDP в ваттах и не меняет автоматически
общий лимит CPU/iGPU. Неудачные значения могут нарушить стабильность.
Температуры кривой должны возрастать, скорости — не уменьшаться. Заводские
настройки сбрасывают после подтверждения также изменения из других программ.
Отмена последнего изменения доступна только после подтверждённой записи.

ПРОФИЛИ И ОТЧЁТ
Ctrl+E сохраняет значения редактора, включая неприменённые, в JSON. Ctrl+I
импортирует профиль только в редактор. Проверяются GPU, диапазоны, единицы,
шаг и кривые. Для записи снова подтвердите Применить. Храните резервные копии
и используйте совместимые профили. RGB не входит в профили ADLX. Ctrl+Shift+S
сохраняет текстовый отчёт. Перед публикацией отчёта проверьте его: он может
содержать идентификаторы оборудования.

ПОДСВЕТКА RGB
Регулировка > Подсветка карты. Сейчас необходим локальный сервер SDK OpenRGB;
независимая аппаратная реализация в эту версию не входит. Загрузить OpenRGB
сохраняет проверенный официальный ZIP. Распакуйте, запустите OpenRGB.exe и
включите сервер SDK, обычно порт 6742. Подключитесь, выберите GPU, режим,
цвет и яркость, затем Применить RGB. Выключить или 0 процентов гасит свет.
Поддержку конкретной модели определяет OpenRGB. Его программа и аппаратные
драйверы не запускаются и не устанавливаются автоматически.

АВТОЗАПУСК, ОБНОВЛЕНИЯ И ОШИБКИ
Автозапуск открывает трей при входе текущего пользователя. Можно настроить
автопроверку, период в минутах и проверку при запуске. Сначала показываются
изменения версии; Да загружает, проверяет и устанавливает, Нет отменяет.
Профили и настройки сохраняются. Старый EXE удаляется после успешного запуска;
если новая версия не запускается, восстанавливается старая.
При ошибке драйвера окно остаётся открытым, чтение повторяется. Запись не
повторяется автоматически. Нажмите F5 и проверьте фактические значения.
Подробности локальных ошибок находятся в Radeoner.log.

ОБНОВЛЕНИЕ ДРАЙВЕРА AMD
Откройте Настройки → Обновления → Обновление драйвера AMD.
Проверьте страницу продукта и прочитайте лицензию AMD. Скачайте полный пакет.
Radeoner проверит подпись, а Windows определит подходящий графический INF.
Если версия новее, подтвердите установку и запрос прав администратора.
Окно обновления Radeoner сразу показывает полный список изменений.
