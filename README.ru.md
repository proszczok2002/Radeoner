# Radeoner

Лёгкая переносимая панель AMD GPU для Windows со стандартными элементами
Windows Forms, управлением с клавиатуры и поддержкой NVDA.

[Polski](README.pl.md) · [English](README.md) · [Deutsch](README.de.md) ·
**Русский** · [Español](README.es.md) · [Français](README.fr.md)

## Загрузка и запуск

1. Скачайте portable ZIP из [выпусков](https://github.com/proszczok2002/Radeoner/releases/latest).
2. Распакуйте все файлы в папку с разрешением на запись.
3. Запустите **Radeoner.exe**. Установщик не требуется.

Требуются Windows 10/11 x64, Microsoft .NET Framework 4.8 и драйвер AMD с ADLX.
Режима Driver Only достаточно, если драйвер содержит ADLX. Панель Adrenalin
не нужна. Библиотека драйвера загружается только из System32; Radeoner
не устанавливает собственный драйвер ядра для управления GPU.

Для Radeoner рекомендуется **Driver Only** в дополнительных параметрах установщика AMD. Если панель Adrenalin остаётся, настраивайте GPU только одной программой. Для обычного обновления оставьте Factory Reset выключенным. При чистой переустановке этот режим удаляет старые пакеты AMD и лишает возможности отката. Для ноутбука также проверьте драйвер производителя.
[Драйверы AMD и старые GPU](docs/AMD_DRIVERS.md) · [AMD](https://www.amd.com/en/resources/support-articles/faqs/RSX2-INSTALL.html)

## Возможности и версия 1.06

- Показания по умолчанию обновляются каждую секунду, в том числе в трее.
- Частоты, напряжение, лимит мощности, кривые вентилятора и Zero RPM доступны,
  только если поддерживаются драйвером. Доступные функции встроенной GPU
  сохраняются; пустые вкладки скрываются.
- Значок встроенной GPU не упоминает вентилятор. Для остальных GPU обороты
  показываются только при корректном измерении, включая допустимые 0 RPM.
- Резервное копирование профилей в JSON. Импорт только заполняет поля;
  запись выполняет **Применить** после подтверждения.
- Шесть языков, системная, светлая и тёмная темы, размер текста 100–200%.
- **F1** открывает полное переведённое руководство без подключения к интернету.
- Поиск обновлений при запуске и через заданный интервал. Изменения показаны
  до установки; профили и настройки сохраняются.

RGB по-прежнему требует необязательный локальный **SDK-сервер OpenRGB**.
Radeoner может скачать проверенный официальный ZIP. Распаковка, запуск OpenRGB
и включение SDK-сервера выполняются отдельно. Собственная реализация доступа
к контроллерам подсветки в 1.06 отсутствует.

## Клавиатура и NVDA

| Клавиши | Действие |
| --- | --- |
| Tab / Shift+Tab | Следующее / предыдущее поле |
| Ctrl+Tab / Ctrl+Shift+Tab | Следующая / предыдущая доступная вкладка |
| Ctrl+1…Ctrl+5 | Показания, Регулировка, Вентилятор, Отчёт, Настройки |
| F5 / F6 / F1 | Обновить / перейти к статусу / справка |
| Ctrl+E / Ctrl+I | Экспорт / импорт профиля |
| Ctrl+Enter | Применить изменения |
| Ctrl+Shift+S | Сохранить отчёт |
| Alt+F4 | Скрыть окно в трей |

Если вкладка Ctrl+1…5 недоступна, открываются Показания. Для полного завершения
выберите **Выход**. К значку можно перейти через Windows+B и нажать Enter.
В списке показаний стрелки выбирают строки; Ctrl+A и Ctrl+C копируют значения.

## Ограничения, файлы и участие

Процентный лимит мощности не равен TDP в ваттах или общему лимиту CPU/iGPU.
Некоторые значения Navi4 являются смещениями — читайте описание поля.
Программа не разблокирует прошивку и не управляет всеми вентиляторами ноутбука.
Физическую запись параметров и RGB нужно проверять на соответствующих картах.
Автотесты не заменяют проверку реальных сообщений NVDA. Текущий
[отчёт проверки](docs/AUDIT_1.06.md) разделяет эти виды подтверждений.

Все шесть переводов и руководств встроены в EXE. Пользовательский UTF-8-файл
`lang/<код языка>.lng` может заменить тексты. Структура portable из восьми
файлов совместима с обновлением из 1.05. Настройки находятся рядом с EXE
в `Radeoner.settings.json`; профили GPU экспортируются отдельно и при запуске
автоматически не применяются.

Публичное обновление 1.05 → 1.06 прошло с неизменными контрольными суммами
профиля и настроек: [отчёт](docs/UPDATE_TEST_1.06.md).
