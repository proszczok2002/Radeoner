# Radeoner 1.08

## English

- The update window focuses a scrollable, read-only field containing the full changelog. **Later** and Escape close the offer before any download.
- AMD driver updates now check the official product page, replacing the Windows Update option. Radeoner downloads the full package after you accept the AMD license, verifies the signature, and compares the compatible graphics INF with the installed driver. Installation uses Windows’ normal driver ranking after confirmation.
- A live Radeon 880M test verified the download, signature, and compatible INF. Automated tests checked the keyboard layout at 200% text size in six languages. Hardware installation and NVDA speech in the new windows still need verification. Reports are welcome, especially with the GPU model, Windows version, and result. [Report an issue](https://github.com/proszczok2002/Radeoner/issues)

## Polski

- Okno aktualizacji od razu ustawia fokus w przewijalnym polu tylko do odczytu z pełną listą zmian. **Później** i Escape zamykają okno przed pobraniem.
- Wyszukiwanie sterowników na oficjalnej stronie produktu AMD zastąpiło opcję Windows Update. Po akceptacji licencji Radeoner pobiera pełny pakiet, weryfikuje podpis i porównuje wersję pasującego INF grafiki z zainstalowanym sterownikiem. Instalacja wymaga potwierdzenia i respektuje preferencje sterowników Windows.
- Na Radeonie 880M sprawdzono pobranie, podpis i zgodność INF. Testy automatyczne objęły klawiaturę przy tekście 200% w sześciu językach. Instalacja sterownika na sprzęcie i odsłuch nowych okien w NVDA pozostają do sprawdzenia. W zgłoszeniu przydadzą się model karty, wersja Windows i wynik. [Zgłoś wynik testu](https://github.com/proszczok2002/Radeoner/issues)

## Deutsch

- Das Updatefenster fokussiert sofort das scrollbare, schreibgeschützte Feld mit allen Änderungen. **Später** und Esc schließen das Fenster vor dem Download.
- Die Treibersuche auf der offiziellen AMD-Produktseite ersetzt die Option für Windows Update. Nach Annahme der AMD-Lizenz lädt Radeoner das vollständige Paket, prüft die Signatur und vergleicht die passende Grafik-INF mit dem installierten Treiber. Windows berücksichtigt bei der bestätigten Installation seine Treiberrangfolge.
- Download, Signatur und passende INF wurden auf einer Radeon 880M geprüft. Automatisierte Tastaturtests liefen bei 200% Textgröße in sechs Sprachen. Installation auf echter Hardware und NVDA-Sprachausgabe in den neuen Fenstern sind noch zu prüfen. Beim Melden bitte GPU-Modell, Windows-Version und Ergebnis angeben. [Ergebnis melden](https://github.com/proszczok2002/Radeoner/issues)

## Русский

- Окно обновления сразу переводит фокус в прокручиваемое поле только для чтения с полным списком изменений. **Позже** и Escape закрывают окно до начала загрузки.
- Поиск на официальной странице продукта AMD заменяет вариант через Центр обновления Windows. После принятия лицензии Radeoner скачивает полный пакет, проверяет подпись и сравнивает подходящий графический INF с установленным драйвером. Для установки нужно подтверждение, а Windows учитывает приоритет драйверов.
- На Radeon 880M проверены загрузка, подпись и совместимость INF. Автоматические проверки клавиатуры выполнены при масштабе текста 200% на шести языках. Установка на реальном оборудовании и озвучивание новых окон в NVDA ещё предстоит проверить. В отчёте укажите модель GPU, версию Windows и результат. [Сообщить результат](https://github.com/proszczok2002/Radeoner/issues)

## Español

- La ventana de actualización enfoca un campo de solo lectura con desplazamiento y la lista completa de cambios. **Más tarde** y Escape cierran la ventana antes de descargar.
- La página oficial del producto AMD sustituye a Windows Update como fuente de controladores. Tras aceptar la licencia, Radeoner descarga el paquete completo, verifica la firma y compara el INF gráfico compatible con el controlador instalado. La instalación requiere confirmación y usa la clasificación de controladores de Windows.
- En una Radeon 880M se verificaron la descarga, la firma y el INF compatible. Las pruebas automáticas de teclado cubrieron texto al 200% en seis idiomas. Quedan por comprobar la instalación en hardware real y la lectura de las nuevas ventanas con NVDA. Indica el modelo de GPU, la versión de Windows y el resultado al informar de una prueba. [Informar de un resultado](https://github.com/proszczok2002/Radeoner/issues)
