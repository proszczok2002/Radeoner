# Radeoner 1.04 — pobieranie OpenRGB / OpenRGB download

## Polski

W **Regulacja → Podświetlenie karty (RGB)** jest przycisk
**Pobierz OpenRGB 1.1 (Windows 64-bit)**. Wybierz miejsce zapisu ZIP w systemowym
oknie. Pobieranie pokazuje procentowy postęp; możesz je anulować. Radeoner
sprawdza rozmiar i SHA-256, a istniejący plik zastępuje dopiero po poprawnej
weryfikacji. Błąd lub anulowanie zachowują poprzedni plik.

Po pobraniu rozpakuj ZIP, uruchom OpenRGB.exe i włącz serwer SDK na porcie 6742.
Wróć do Radeonera i wybierz **Połącz z OpenRGB**. Program nie instaluje ani nie
uruchamia OpenRGB automatycznie. Otworzenie okna RGB nie łączy się z internetem.
Obsługa konkretnej karty RGB zależy od OpenRGB.

Walidacja: 51 testów, rzeczywiste pobranie oficjalnego ZIP przez nowy kod oraz
pełna lokalna aktualizacja 1.03 → 1.04 z zachowaniem preferencji i profilu.
Kontrole dostępności sprawdzają nazwy i strukturę kontrolek; w tym wydaniu
nie wykonano odsłuchu NVDA ani fizycznego testu RGB karty.

## English

**Tuning → GPU lighting (RGB)** now has **Download OpenRGB 1.1 (Windows 64-bit)**.
Choose a ZIP destination in the native Save dialog. Download status shows
percentage progress and supports cancellation. Size and SHA-256 are checked
before replacing the destination; failed/cancelled downloads preserve existing
files. Extract the ZIP, run OpenRGB.exe and enable the SDK server on port 6742,
then **Connect to OpenRGB** in Radeoner.

OpenRGB is not installed or started automatically. Opening the RGB dialog
makes no internet connection. GPU lighting support depends on OpenRGB.

Validation: 51 tests, a real official ZIP download through the new code, and
a full local 1.03 → 1.04 update preserving preferences and a profile. Automated
accessibility checks cover control names/structure; no NVDA listening session
or physical GPU RGB test was performed for this release.
