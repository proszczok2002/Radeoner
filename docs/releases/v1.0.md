## Polski

Pierwsze publiczne wydanie **Radeonera** — lekkiego, przenośnego panelu AMD dla
Windows z interfejsem Microsoft WinForms i obsługą klawiatury/czytników ekranu.

- Odczyty GPU i regulacje udostępniane przez sterownik ADLX, bez panelu Adrenalin.
- Profile JSON, krzywe wentylatorów, tray i opcjonalny autostart.
- Motywy, tekst 100–200%, Polski/English z plików LNG.
- Updater: sprawdzanie przy starcie i okresowo, pobranie z GitHuba, SHA-256,
  podmiana EXE i usunięcie starego pliku po potwierdzeniu startu nowej wersji.
- Publiczny kod MIT, dokumentacja PL/EN, zasady współpracy i testy CI.

Pobierz ZIP i rozpakuj cały folder; uruchom **Radeoner.exe**. Windows 10/11 x64,
.NET Framework 4.8 i sterownik AMD z ADLX. Dostępne funkcje zależą od GPU
i firmware. Nie każda integra/laptop udostępnia regulację. Odsłuch z prawdziwym
NVDA i fizyczne zapisy na kartach z regulacją wymagają dalszej weryfikacji.

Weryfikacja: **34 testy**, kompilacja z czystego eksportu źródeł oraz lokalny
pełny test 1.0 → 1.01, z zachowaniem preferencji i profilu.

## English

First public **Radeoner** release: a lightweight, portable AMD GPU panel for
Windows with Microsoft WinForms, keyboard navigation and screen-reader labels.

- Driver-exposed ADLX monitoring/tuning without the Adrenalin control panel.
- JSON profiles, fan curves, tray readings and optional Windows startup.
- Themes, text size 100–200%, Polish/English LNG files.
- GitHub updater with startup/scheduled checks, SHA-256 verification, EXE
  replacement and old-file removal after confirmed new-version startup.
- Public MIT source, bilingual docs, contribution guidance and Windows CI.

Download and extract the complete ZIP, then run **Radeoner.exe**. Requires
Windows 10/11 x64, .NET Framework 4.8 and an AMD driver providing ADLX. Hardware
and firmware determine tuning support. Real NVDA listening and physical tuning
writes need further community validation.

Validation: **34 tests**, a clean-source build, and a complete local 1.0 → 1.01
replacement/startup/cleanup test preserving preferences and a user profile.
