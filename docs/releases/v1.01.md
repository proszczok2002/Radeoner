## Polski

**Wydanie do sprawdzenia aktualizacji 1.0 → 1.01.** Numer wewnętrzny: 1.0.1.0.
Funkcje GPU pozostają takie jak w 1.0; nowy numer pozwala sprawdzić rzeczywiste
pobranie z GitHuba, podmianę EXE i usunięcie starej wersji po potwierdzonym starcie.

W wersji **1.0** otwórz **Aktualizacje → Sprawdź teraz → Pobierz i zainstaluj**.
Profile i preferencje są zachowywane. Zapisz niezastosowane pola jako profil
przed restartem. Możesz też pobrać i rozpakować ZIP 1.01 ręcznie.

Źródła i dokumentacja PL/EN: [repozytorium](https://github.com/proszczok2002/Radeoner).
Przeszły 34 testy automatyczne; ograniczenia obsługi sprzętu i NVDA opisano
w README i dokumentacji weryfikacji.

## English

**Release for testing the 1.0 → 1.01 self-update.** Internal version: 1.0.1.0.
GPU functionality is unchanged from 1.0. The new version exercises an actual
GitHub download, EXE replacement and old-version removal after confirmed startup.

In **1.0**, open **Updates → Check now → Download and install**. Preferences
and profiles are preserved. Export unapplied editor values before restarting.
You can also download and extract the 1.01 ZIP manually.

Source and bilingual documentation: [repository](https://github.com/proszczok2002/Radeoner).
34 automated tests pass. Hardware and NVDA validation limitations remain
documented in the README and validation notes.
