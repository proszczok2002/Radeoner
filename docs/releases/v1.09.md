# Radeoner 1.09

## English

- **Settings → AMD background components** can disable recognized AMD Install Manager and legacy updater tasks and services, plus supported Adrenalin startup tasks. The option targets optional components with an AMD signature.
- Windows asks for administrator permission. Clear the check box to restore the saved settings. If an installation or update is in progress, wait for it to finish.
- Automated tests cover keyboard focus, cancellation, and recovery after a partial failure. Changes to AMD services on real hardware and speech in NVDA still need confirmation. [Report a result](https://github.com/proszczok2002/Radeoner/issues)

## Polski

- W **Ustawieniach → Składniki AMD w tle** można wyłączyć rozpoznane zadania i usługi AMD Install Managera i starszego aktualizatora oraz zadania uruchamiające Adrenalin. Opcja obejmuje dodatkowe składniki z podpisem AMD.
- Windows poprosi o uprawnienia administratora. Odznacz pole, aby przywrócić zapisane ustawienia. Jeśli trwa instalacja lub aktualizacja, zaczekaj na jej zakończenie.
- Testy automatyczne objęły fokus klawiatury, anulowanie i przywracanie po częściowym błędzie. Zmiany usług AMD na rzeczywistym sprzęcie i odczyt NVDA wymagają jeszcze potwierdzenia. [Zgłoś wynik](https://github.com/proszczok2002/Radeoner/issues)

## Deutsch

- Unter **Einstellungen → AMD-Hintergrundkomponenten** lassen sich erkannte Aufgaben und Dienste von AMD Install Manager und dem älteren Updater sowie unterstützte Startaufgaben von Adrenalin deaktivieren. Die Option gilt für optionale Komponenten mit AMD-Signatur.
- Windows fragt nach Administratorrechten. Entfernen Sie den Haken, um die gespeicherten Einstellungen wiederherzustellen. Warten Sie, bis laufende Installationen oder Updates abgeschlossen sind.
- Automatisierte Tests prüfen Tastaturfokus, Abbruch und Wiederherstellung nach einem Teilfehler. Änderungen an AMD-Diensten auf echter Hardware und die NVDA-Sprachausgabe sind noch zu bestätigen. [Ergebnis melden](https://github.com/proszczok2002/Radeoner/issues)

## Русский

- В разделе **Настройки → Фоновые компоненты AMD** можно отключить распознанные задачи и службы AMD Install Manager и прежнего средства обновления, а также поддерживаемые задачи запуска Adrenalin. Опция применяется к необязательным компонентам с подписью AMD.
- Windows запросит права администратора. Снимите флажок, чтобы восстановить сохранённые настройки. Если идёт установка или обновление, дождитесь завершения.
- Автоматические тесты проверяют фокус клавиатуры, отмену и восстановление после частичной ошибки. Изменение служб AMD на реальном оборудовании и озвучивание в NVDA ещё предстоит подтвердить. [Сообщить результат](https://github.com/proszczok2002/Radeoner/issues)

## Español

- En **Ajustes → Componentes de AMD en segundo plano** puedes desactivar las tareas y servicios reconocidos de AMD Install Manager y del actualizador anterior, además de las tareas de inicio de Adrenalin compatibles. La opción se aplica a componentes opcionales firmados por AMD.
- Windows solicitará permisos de administrador. Desmarca la casilla para restaurar la configuración guardada. Si hay una instalación o actualización en curso, espera a que termine.
- Las pruebas automatizadas cubren el foco del teclado, la cancelación y la recuperación tras un fallo parcial. Quedan por confirmar los cambios de servicios en hardware real y la lectura con NVDA. [Informar de un resultado](https://github.com/proszczok2002/Radeoner/issues)

## Français

- Dans **Paramètres → Composants AMD en arrière-plan**, vous pouvez désactiver les tâches et services reconnus d’AMD Install Manager et de l’ancien outil de mise à jour, ainsi que les tâches de démarrage d’Adrenalin prises en charge. L’option vise les composants facultatifs signés par AMD.
- Windows demandera des droits d’administration. Décochez la case pour rétablir les paramètres enregistrés. Attendez la fin de toute installation ou mise à jour en cours.
- Les tests automatisés couvrent le focus clavier, l’annulation et la restauration après un échec partiel. La modification des services AMD sur du matériel réel et la lecture avec NVDA restent à confirmer. [Signaler un résultat](https://github.com/proszczok2002/Radeoner/issues)
