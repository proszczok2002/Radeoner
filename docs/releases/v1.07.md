# Radeoner 1.07

## English

- Search for and install AMD graphics driver updates from **Settings → Updates → AMD driver updates**. Choose a package, review the license when required and confirm the operation in Radeoner. Windows asks for administrator permission. Radeoner tells you if a restart is required.
- Offers come from your computer’s Windows Update catalog and can differ from the versions on AMD’s website.
- OpenRGB discovery retries after rescans. If the confirmation is delayed, Radeoner reads the lighting state again. Each lighting command is sent once.
- The driver update dialog and its keyboard controls were tested at 200% text size in all six languages. A live scan on Radeon 880M returned no offers. Installation on hardware and NVDA speech in the new dialog remain unverified.

## Polski

- W **Ustawienia → Aktualizacje → Aktualizacja sterownika AMD** możesz wyszukać sterownik, wybrać pakiet, przeczytać warunki licencji i zatwierdzić instalację. Windows poprosi o uprawnienia administratora. Radeoner poinformuje, jeśli trzeba ponownie uruchomić komputer.
- Pakiety pochodzą z Windows Update i mogą się różnić od wersji dostępnych na stronie AMD.
- Radeoner ponawia wykrywanie urządzeń po ponownym skanowaniu OpenRGB. Przy opóźnionym potwierdzeniu odczytuje stan podświetlenia ponownie. Polecenie zmiany podświetlenia wysyła raz.
- Przetestowano obsługę klawiaturą i tekst 200% w oknie aktualizacji sterownika w sześciu językach. Wyszukiwanie na Radeonie 880M nie zwróciło pakietu. Instalacja sterownika na sprzęcie i odczyt nowego okna przez NVDA pozostają do sprawdzenia.

## Deutsch

- Unter **Einstellungen → Aktualisierungen → AMD-Treiber aktualisieren** können Sie einen Grafiktreiber suchen, auswählen und installieren. Bei Bedarf werden die Lizenzbedingungen angezeigt. Windows fordert Administratorrechte an. Radeoner meldet einen erforderlichen Neustart.
- Die angebotenen Treiber stammen aus Windows Update und können von den Versionen auf der AMD-Website abweichen.
- Radeoner wiederholt die OpenRGB-Geräteerkennung nach einem erneuten Scan. Bei verzögerter Bestätigung liest es den Beleuchtungszustand erneut aus. Jeder Beleuchtungsbefehl wird einmal gesendet.
- Tastaturbedienung und 200% Textgröße im neuen Dialog wurden in allen sechs Sprachen getestet. Die Suche auf einer Radeon 880M ergab keine Angebote. Die Installation auf echter Hardware und die NVDA-Sprachausgabe im neuen Dialog sind noch zu prüfen.

## Русский

- В разделе **Настройки → Обновления → Обновление драйвера AMD** можно найти, выбрать и установить драйвер видеокарты. При необходимости окно показывает условия лицензии. Windows запрашивает права администратора. Radeoner сообщает, если требуется перезапуск.
- Драйверы поступают из Центра обновления Windows и могут отличаться от версий на сайте AMD.
- Radeoner повторяет обнаружение устройств после нового сканирования OpenRGB. При задержке подтверждения он снова считывает состояние подсветки. Каждая команда подсветки отправляется один раз.
- Проверены управление с клавиатуры и масштаб текста 200% в новом окне на всех шести языках. Поиск на Radeon 880M не нашёл обновлений. Установку на реальном оборудовании и озвучивание нового окна в NVDA ещё предстоит проверить.

## Español

- En **Ajustes → Actualizaciones → Actualizar controlador AMD** puedes buscar, elegir e instalar un controlador de gráficos y consultar su licencia si es necesario. Windows solicita permisos de administrador. Radeoner indica si hace falta reiniciar.
- Los controladores provienen de Windows Update y pueden diferir de las versiones del sitio web de AMD.
- Radeoner reintenta detectar dispositivos después de un nuevo escaneo de OpenRGB. Si se retrasa la confirmación, vuelve a leer el estado de la iluminación. Cada comando de iluminación se envía una vez.
- Se probó el manejo con teclado y el tamaño del texto al 200% en los seis idiomas. La búsqueda en una Radeon 880M no ofreció actualizaciones. Quedan por comprobar la instalación en hardware real y la lectura del nuevo diálogo con NVDA.

## Français

- Dans **Paramètres → Mises à jour → Mettre à jour le pilote AMD**, recherchez, choisissez et installez un pilote graphique. Les conditions de licence sont accessibles si nécessaire. Windows demande les droits d’administration. Radeoner signale si un redémarrage est requis.
- Les pilotes proviennent de Windows Update et peuvent différer des versions du site d’AMD.
- Radeoner relance la détection après une nouvelle recherche OpenRGB. En cas de confirmation tardive, il relit l’état de l’éclairage. Chaque commande d’éclairage est envoyée une seule fois.
- La navigation au clavier et le texte à 200% ont été testés dans les six langues. La recherche sur une Radeon 880M n’a proposé aucun pilote. L’installation sur le matériel et la lecture du nouveau dialogue avec NVDA restent à vérifier.
