# Radeoner 1.05 — dostępność i wygląd / Accessibility and appearance

## Polski

- Poprawiony układ przy tekście 100–200%: miejsce na zakładkę, wyrównane pola,
  zawijane opisy i przewijanie całego pola z fokusem.
- Spójne motywy pól i przycisków; pomoc, pełne zmiany i RGB dopasowane do
  motywu i wielkości tekstu. Zachowano natywne kontrolki Windows.
- Usunięty podwójny odczyt nazw i zakresów pól liczbowych przez NVDA.
  Nazwa, jednostka, wartość i zakres pozostają dostępne, strzałki działają.
- Czytelna nazwa grupy zakładek, dostępne Tab wyjaśnienia braku obsługi,
  wskazanie błędnego pola oraz osłony przy zamykaniu okien RGB.

Sprawdzono 540 punktów rzeczywistego tekstu Podglądu mowy NVDA, 60 punktów
dialogów systemowych, rzeczywiste skróty Ctrl+Tab/Ctrl+Shift+Tab, klawisze
pola liczbowego, ikonę traya i Enter przywracający okno. 57 testów regresji.

[Wyniki i ograniczenia audytu](https://github.com/proszczok2002/Radeoner/blob/main/docs/AUDIT_1.05.md).
Weryfikowano tekst wypowiedzi NVDA, nie nagranie audio. Fizycznego RGB TUF
i obciążenia RX 9060 w tym audycie nie testowano.

## English

- Responsive 100–200% text layout with usable tab space, aligned fields,
  wrapped descriptions and scrolling to the complete focused control.
- Consistent field/button themes and scalable, themed help/details/RGB dialogs,
  preserving native Windows controls and accessibility providers.
- Removed duplicated NVDA numeric labels and ranges. Focused spin controls
  retain names, units, values, ranges and working arrow-key input.
- Short tab-group name, focusable unsupported-feature explanations,
  invalid-field focus recovery and closing guards for RGB operations.

Validation: 540 actual NVDA Speech Viewer UI checkpoints, 60 native-dialog
checkpoints, real Ctrl+Tab/Ctrl+Shift+Tab and numeric keys, Shell tray speech
and Enter-to-restore; 57 regression tests. The audit reviewed speech text,
not recorded audio. Physical TUF RGB/RX 9060 load testing was outside this audit.

Preferences and JSON profiles are preserved by the updater.
