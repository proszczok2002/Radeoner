# Radeoner 1.06

## Polski

- Zakładki i pola dopasowane do możliwości sterownika: puste Regulacja i
  Wentylator są pomijane. Obsługiwane funkcje integry pozostają dostępne.
- Ctrl+Tab i Ctrl+Shift+Tab przechodzą przez dostępne zakładki; Ctrl+1…5
  zachowują stałe znaczenie, a niedostępna zakładka przekierowuje do Odczytów.
- Tray integry nie wspomina o wentylatorach. Na pozostałych GPU obroty są
  podawane wyłącznie z poprawnego odczytu; 0 RPM pozostaje poprawną wartością.
- Niemiecki, rosyjski, hiszpański i francuski uzupełniają polski i angielski.
  Pełne instrukcje we wszystkich sześciu językach są dostępne offline przez F1.
- Czytelniejszy układ ustawień dla długich tłumaczeń i tekstu 200%.
- Nowe języki są wbudowane w EXE; zachowano format paczki obsługiwany przez
  aktualizator 1.05. Profile i preferencje pozostają zachowane.

RGB nadal wymaga opcjonalnego OpenRGB. Niezależna obsługa kontrolerów nie jest
częścią tego wydania: [stan prac](../NATIVE_RGB.md).

## English

- Driver capabilities determine visible controls and tabs. Empty Tuning/Fan
  pages are omitted; supported integrated-GPU features remain available.
- Ctrl+Tab and Ctrl+Shift+Tab cycle through available pages. Ctrl+1…5 keep
  their logical targets; unavailable targets return to Readings.
- Integrated-GPU tray text never announces fans. Other GPUs announce only
  valid RPM readings, including a stopped fan at 0 RPM.
- German, Russian, Spanish and French join Polish and English. Complete
  translated guides are embedded and available offline through F1.
- Settings layout handles long translations and 200% text more clearly.
- New languages are embedded in the EXE, retaining the eight-file package
  accepted by the 1.05 updater. Profiles and preferences are preserved.

RGB still requires optional OpenRGB. A native controller backend is not
included: [native RGB status](../NATIVE_RGB.md).
