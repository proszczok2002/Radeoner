# Radeoner 1.06 → 1.07

## English

The 1.06 updater passed with the local package and through the public GitHub
channel. Both used an isolated copy of 1.06. The 1.07 window confirmed startup.
The old executable and update helper were cleaned up, and the preference and
profile files kept their original checksums.
[Published 1.07 release](https://github.com/proszczok2002/Radeoner/releases/tag/v1.07)

## Polski

Aktualizator 1.06 przeszedł test z paczki lokalnej i z publicznego kanału
GitHub. Oba testy działały na osobnej kopii 1.06. Okno 1.07 potwierdziło start.
Stary EXE i pomocnik aktualizacji zostały uprzątnięte. Pliki preferencji
i profilu zachowały sumy kontrolne.

## Deutsch

Der Updater von 1.06 wurde mit einem lokalen Paket und über den öffentlichen
GitHub-Kanal in separaten Kopien getestet. Das Fenster von 1.07 bestätigte den
Start. Alte EXE und Update-Hilfsprogramm wurden entfernt. Die Prüfsummen der
Profil- und Einstellungsdateien blieben unverändert.

программа обновления удалены. Контрольные суммы профиля и настроек сохранились.
